# df-backend-rPPG
This consist of 3 models, CNN, ViT and rPPG to develop

1. clone backend rppg: git clone "https://github.com/spcf-deepfake-detector/df-backend-rPPG.git"

2. activate virtual environment: source .brPPG/bin/activate

3. install requirements.txt: python -m pip install -r requirements.txt
